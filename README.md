# Personal Website - Biswajit Singha

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ✨ Smooth animations and transitions
- 🔗 Smooth scroll navigation
- 📱 Mobile-friendly
- ⚡ Fast and lightweight

## Sections

1. **Navigation Bar** - Sticky navbar with smooth scrolling
2. **Hero Section** - Eye-catching introduction
3. **About** - Tell your story
4. **Projects** - Showcase your work
5. **Contact** - Get in touch section with social links
6. **Footer** - Copyright information

## Getting Started

1. Clone this repository
   ```bash
   git clone https://github.com/singhabiswajit/biswajitsingha.git
   ```

2. Open `index.html` in your browser
   ```bash
   open index.html
   ```

## Customization

### Update Personal Information
- Edit the content in `index.html` with your information
- Update social media links in the contact section
- Change your email in the contact section

### Customize Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #3498db;
    --secondary-color: #2c3e50;
    --light-bg: #ecf0f1;
    --text-color: #2c3e50;
    --white: #ffffff;
}
```

### Add Projects
Duplicate the `.project-card` div in the Projects section and update with your project details.

## Technologies Used

- HTML5
- CSS3 (with animations and flexbox/grid)
- Vanilla JavaScript

## Deploy on GitHub Pages

1. Go to repository settings
2. Navigate to "Pages"
3. Select `main` branch as the source
4. Your site will be live at `https://singhabiswajit.github.io/biswajitsingha`
